# Web Developer Portfolio

Rails API / React / TypeScript / PostgreSQL を用いたWebアプリケーション開発の制作実績をまとめた、就職活動用ポートフォリオサイトです。

## 概要

このサイトでは、個人開発で作成したWebアプリケーションを一覧で確認できます。  
採用担当者や現場エンジニアの方が、制作物の概要、使用技術、デモURL、GitHubリポジトリ、テストユーザー情報をすばやく確認できることを目的にしています。

## 目的

企業応募時に提出できるポートフォリオとして、これまで取り組んできたWebアプリケーション開発の経験を分かりやすく整理するために作成しました。

## 掲載している制作実績

### ミニSNSアプリ

XのようなSNSをイメージしたWebアプリです。  
ユーザー登録、ログイン、投稿、返信、いいね、フォロー、プロフィール編集などを実装しています。

※ 現在は未デプロイです。

### JOB HUNT MANAGER

就職活動の応募状況を管理するWebアプリです。  
企業、求人、応募、面接、タスク、メモをユーザーごとに管理できます。

### TaskFlow

チームで使うことを想定したタスク管理アプリです。  
タスク作成、担当者設定、ステータス管理、進捗確認などを実装しています。
